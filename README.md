# Treino Tracker — V1.00

Aplicativo PWA do diário de treino.

## Conteúdo
- Ficha completa de quarta a domingo
- Aquecimento
- RIR/intensidade
- Descanso individual
- Reps, RPE e carga
- Cronômetro
- Conclusão do treino
- Histórico
- Progresso
- Avaliação de peso e % de gordura
- Metas de proteína, água e sono
- Exportação de backup JSON
- Funcionamento offline após o primeiro carregamento

## Instalação no iPhone
Para instalar como app na Tela de Início, publique estes arquivos em um endereço HTTPS (GitHub Pages, Netlify, Vercel etc.) e abra o endereço no Safari. Depois: Compartilhar → Adicionar à Tela de Início.
